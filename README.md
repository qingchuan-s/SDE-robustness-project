# Robust Parameter Estimation in Dynamical Systems (ODE vs SDE)

This repository contains the R code to reproduce the simulation studies and data analysis in:

**Qingchuan Sun, Susanne Ditlevsen**  
*Robust Parameter Estimation in Dynamical Systems by Stochastic Differential Equations*  
(preprint)

The paper studies the robustness of parameter estimation in stochastic differential equation (SDE) models compared to ordinary differential equation (ODE) models under different types of model misspecification, including external perturbations, unrecognized noise sources, mismatch of models, and missing/incomplete data.

---

## Overview

The code in this repository reproduces results from the following topics of the paper:

- Linear SDE/ODE model with perturbations
- Stochastic and deterministic SIR and SEIR epidemic models
- Comparison of parameter estimates under:
  - Correctly specified models
  - Misspecified noise structure
  - Instantaneous perturbations
  - Simplified models
  - Missing/incomplete data scenarios (COVID-19 data)

The focus is on demonstrating that **SDE-based estimation provides more stable and robust parameter estimates** than ODE-based estimation in the presence of uncertainty and model misspecification.

## Models implemented

### Linear model
- Deterministic ODE
- Ornstein–Uhlenbeck SDE
- Estimation under:
  - Measurement noise
  - System noise
  - Instantaneous perturbations
  - Misspecified drift

### Epidemic models
- SIR (ODE and SDE)
- SEIR (ODE and SDE)
- Pseudo-likelihood estimation using Strang splitting
- Comparison between:
  - Deterministic vs stochastic data-generating processes
  - Correct vs simplified fitted models

## Reproducibility notes
- Random seeds are set within scripts where relevant.
- Simulation results may vary slightly due to stochasticity.
- Computation time depends on the number of Monte Carlo repetitions.
